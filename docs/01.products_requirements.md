# 상품 목록 페이지 요구사항 분석 및 기능 목록

## 📌 기본 정보
### 프로젝트명: 
신발 쇼핑몰(슈킹) 상품 목록 페이지 (모바일)

### 사용하게 될 기술: 
React, html, html

### 문서 작성자: 이채원

## 📝 고객 요구사항 정리
1. 아이쇼핑에 친숙한 젊은세대(20~30대) 겨냥 모바일 웹앱
2. 상품목록은 상품명보다는 사진 위주
3. 실시간 장바구니 목록 개수 변경 반영
4. 결과물 확인용 TEST URL


## 📋 기능 목록
- 상품 리스트
- 사진 위주 (상품명 보다)
- 2개의 컬럼으로 구성된 상품 목록 레이아웃 기능
- 담기 버튼 이후 상품목록 갯수 변화 기능
