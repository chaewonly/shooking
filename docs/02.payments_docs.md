# 결제 모듈 프로젝트

## 프로젝트 개요
20~30대 젊음 세대 겨냥 신발 쇼핑몰(shooking) 웹 구현
 -모바일 UI
 -상품 사진
 -장바구니에 담긴 상품 갯수 실시간 업데이트
 -배포 URL
 -기능 목록 체크리스트
 -이미지가 포함된 상품 카드
 -2개의 컬럼으로 구성된 상품 목록 레이아웃
 -상품 카드에서 담기 버튼과 담김 상태 변화
 -담기 버튼을 누른 후, 헤더에 담긴 상품의 갯수 변화
팀원: 이채원

## 개발 환경

Reac, JavaScript

## 설치 및 실행 방법
npm install
npm start
